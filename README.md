## Install

```bash
scoop bucket add bartoszosiej https://github.com/BartoszOsiej/scoop-bucket
scoop install bartoszosiej/tap/netrecon
scoop install bartoszosiej/tap/hashsleuth
```

## What's inside

| Formula | Description | Platforms |
|---|---|---|
| [netrecon](https://github.com/BartoszOsiej/cybersec-tools) | Fast network reconnaissance — host discovery & port scanning | Windows x86_64 |
| [hashsleuth](https://github.com/BartoszOsiej/cybersec-tools) | Multi-threaded hash identification & cracking toolkit | Windows x86_64 |

## How it stays fresh

An hourly `auto-bump` workflow watches the
[cybersec-tools releases](https://github.com/BartoszOsiej/cybersec-tools/releases),
downloads every Windows x64 binary, computes real SHA-256 sums and rewrites the
manifests. No human hands, no stale versions.

Every binary ships with a **SLSA v1 build provenance attestation** generated by
GitHub Actions — verify with `gh attestation verify`.
